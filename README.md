# 🦷 歯磨き記録

ブラウザの localStorage だけで動く、シンプルな歯磨き記録アプリです。サーバー・ビルド不要で GitHub Pages にそのまま置けます。

## ✨ 主な機能
- 「はみがき / デンタルフロス」をタップして記録（もう一度タップで取り消し）
- `<` `>` ボタンで記録する日付を過去に移動可能（未来には進めません）
- 「今日に戻る」でワンタップで当日表示に復帰
- デンタルフロスを2日連続でしていないと、今日の画面に注意メッセージを表示（フロスは2日に1回ペース想定）
- 連続記録日数（ストリーク）を「はみがき」「フロス」それぞれ個別にリアルタイム表示
- 直近の記録履歴を一覧表示
- その日のメモを30文字まで記録可能
- 記録データをCSVファイルとしてエクスポート / インポート可能（インポート時は「洗替（全置き換え）」「上書き（同じ日付だけ更新）」を選択可能）
- 子ども向けのかわいい丸ゴシックフォント（Google Fonts「Yusei Magic」）とパステルカラーのデザイン
- 記録は端末の localStorage に保存（サーバー通信なし）
- 子ども向けの すいぞくかん（下記）

## 🐠 すいぞくかん（小学校低学年向け）
はみがき・フロスを記録すると、月ごとの すいそうに いきものが ふえていきます。画面の文は ひらがな・カタカナ中心です。
- **はみがき → さかな**: はみがきした日は さかなが1ぴき すいそうに来ます。両方できた日は めずらしい いきもの（ロブスター・ペンギン・いるか・にんぎょ など）が出やすくなります
- **フロス → かざり**: フロスした日は みずくさ・かいがら・いわ などが すいそうの底に ふえます
- **とくべつな おきゃくさん**: 両方の連続日数が 7・14・30・100日に届くと 🐢🐙🐋🐉 が来ます（何が来るかは来るまでのおたのしみ）
- **月ごとの すいそう**: 月が変わると新しい すいそうになり、前の月は「これまでの すいそう」に並びます。毎日はみがきできた月には 👑
- **いきもの ずかん**: 来た いきものの種類を集めます（全19種）。さかなをタッチすると、いつ来たかが分かります
- **ペナルティなし**: サボっても何も減りません（来ないだけ）
- **状態は保存しない**: すいそうの中身は記録データから毎回計算します。乱数は日付から決まるため、同じ記録なら同じ いきものが来ます（引き直し不可）。CSV を取り込めば すいそうも元に戻ります。それまでの記録もさかのぼって反映されます
- **おうちの人むけ**: CSV の書き出し・読み込みは、子どもが誤って「洗替」しないよう、ページ下部の折りたたみ「👪 おうちの人むけ」の中にあります

## 🚀 使い方
1. `index.html` をブラウザで開きます。
2. 「歯磨き」「フロス」のボタンをタップすると、表示中の日付に記録されます。
3. `<` `>` で日付を移動すれば、記録し忘れた過去の日の記録も後から追加できます。
4. 両方記録すると「コンプリート」表示が出ます。
5. メモ欄に一言（30文字まで）を入力すると、その日の記録として一緒に保存されます。
6. ページ下部の「👪 おうちの人むけ」を開き、「📤 書き出す」ボタンで、これまでの記録を `hamigaki-kiroku_YYYYMMDD.csv` としてダウンロードできます。
7. 「📥 読み込む」ボタンで保存済みのCSVファイルを選ぶと、見つかった日数と取り込み方法（洗替 / 上書き）を選ぶダイアログが出ます。Excel で保存し直したCSV（Shift_JIS、`2026/9/1` 形式の日付、`〇` や `1`）も読み込めます。
   - **洗替**: 今のデータを全部消してCSVの内容に置き換えます。
   - **上書き**: CSVにある日付だけ更新し、それ以外の日の記録はそのまま残します。
8. ページを再読み込みしても記録は端末に保存されたまま残ります。

## 🛠️ 技術構成
- HTML / CSS / JavaScript（フレームワーク未使用）
- データ保存: `localStorage`（キー: `hamigakiLog`）
- `aquarium.js`: すいぞくかんのロジック（DOM に依存しない純粋関数）。`main.js`: 画面とデータ保存
- テスト: `node --test`（Node.js 18 以上、追加パッケージ不要）
- フォント: Google Fonts「Yusei Magic」をCDN経由で読み込み（オフライン環境では既定フォントにフォールバック）

## 🌐 GitHub Pages への公開手順
1. このフォルダの内容で GitHub リポジトリを作成し、`main` ブランチに push します。
2. リポジトリの Settings → Pages を開きます。
3. 「Source」を `Deploy from a branch` にし、ブランチを `main` / フォルダを `/ (root)` に設定して Save します。
4. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
